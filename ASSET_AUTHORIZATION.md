# Asset and chunk-data authorization note

The project owner supplied correspondence stating that use of **Mindustry game assets and chunk data for this web-port project is approved**, provided the project complies with Mindustry's GPLv3 terms and gives proper attribution.

This workbench therefore intentionally uses the real assets from the pinned Mindustry checkout (`core/assets`) rather than placeholder art. The private correspondence screenshots are **not bundled** in this kit. This note records only the project-owner-supplied authorization context; it is not an independent authentication of the sender.

The authorization does not replace license compliance. Any distributed modified build must still preserve the applicable GPLv3 notices, attribution, and corresponding-source obligations.
